# Clube do Fausto 🐾

A private book club app for two readers: twelve books from twelve countries in 2027, a literary passport, page tracking, a book chat, quizzes with Fausto the cat, and notifications.

It is a static web app (one `index.html`, a service worker and a manifest), installable on phones from the browser ("Add to Home Screen").

There is no club data in this repository. Readers join a club with a private invite link, and progress syncs through a small Supabase database.
